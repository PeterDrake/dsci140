# Locating Data
You need to locate a reputable data set (or sets) to download and use for your project. There are many organizations that collect data carefully and then post it online for others to use. [Here is a list of good data sources.](https://docs.google.com/document/d/1yKQKPOz2Vt8EsXmYjZ-dOUa1UAk-Y46A8lsZKdBVbCM/edit?usp=drive_link) There are definitely more! You will almost certainly have to do some web searching to find data on your particular topic. Feel free to recommend a data source that your instructor can add to this list.

Be sure you can actually acquire the relevant data as, for example, a .csv or .xlsx file.

Some data wrangling may be in order. If you have a spreadsheet that is not a single table, you may need to do some cutting and pasting to reformat it.

You should not edit the data themselves in a spreadsheet. We will see later in the course how to do some data cleaning with Python. Doing the cleaning with code, rather than by hand, makes it easier for other researchers to reproduce your work.
